# Logseq 插件：Left-Sidebar Enhance

> 一个 Logseq 插件，增强左侧边栏功能：页面大纲（目录）、标题层级编号、自动标题等级调整、鼠标悬停唤出侧边栏等。

## 功能

### 1. 页面大纲（目录）

根据当前页面的标题（`#` 到 `######`）自动在左侧边栏生成目录。

- **单击** → 跳转到标题位置
- **Ctrl+单击** → 以缩放页面打开
- **Shift+单击** → 在右侧边栏中打开
- **悬停高亮** → 鼠标悬停目录项时高亮对应数据块；聚焦某数据块时高亮其目录项
- **日记支持** → 在日记页面显示日期列表（可在设置中开关）

### 2. 标题层级编号（仅限文件型图谱）

通过工具栏按钮手动为 Markdown 标题添加层级编号（如 `1`、`1.1`、`1.1.1`）—— 纯按钮触发，无后台监听，无性能损耗。

- **工具栏按钮** → 点击「重新编号」为当前页面编号
- **块右键菜单**（状态写入块属性 `numbering::`）：
  - **跳过**（`skip`）— 跳过此标题，不参与编号；其子标题继承父级编号前缀
  - **跳过整棵子树**（`skip-subtree`）— 此标题及其所有子标题都不参与编号
  - **锁定**（`locked`）— 保持当前编号不变；后续同级标题从该编号递增
  - **重复上一个**（`repeat`）— 与上一个同级标题使用相同编号
- **状态图标** → 标题块前方的圆点会变成对应图标：跳过 ⊘、跳过整棵子树 ⊘（带内圈）、重复 ⧉、锁定 🔒（SVG 线稿，跟随主题文字颜色）
- **跳过整棵子树会清理旧编号** → 标记后每次编号都会递归移除该子树内已有的编号（保留 `locked` 与 `repeat` 块）
- **状态跟着块走** → 状态保存在块属性中，复制/移动块时自动跟随，跨图谱同步
- **多位数字保护** → 标题开头的 3 位及以上数字（`100`–`9999`）视为正文，标题照常编号（`## 2002 的` → `## 1 2002 的`）
- **可查询** → 支持 `{{query (property numbering skip)}}` 之类的属性查询

> 需要让同类章节在不同笔记中保持固定编号？见下一节「特定 Tag 笔记按照预设规则编号」。

### 3. 特定 Tag 笔记按照预设规则编号（仅限文件型图谱）

带**特定 tag** 的笔记，可以按预先写好的规则编号，而不是简单地从 1 开始顺序递增。

规则由若干「区间（category）」组成，每个区间有自己的编号前缀；标题按关键词落到某个区间，再在区间内递增。这样同一含义的章节在不同笔记中就能保持稳定的编号。

#### 编号方式

```
编号 = 区间ID × 10 + 区间内序号
```

- 区间 ID 决定编号前缀（`id: 2` → 该区间的标题从 `21`、`22`… 开始）
- 区间 1 可以使用「位置法」：把第一个命中其他区间关键词的标题作为分界，它之前的标题全部归入区间 1，数量不固定也不影响后面的编号
- 区间 2 及其后按关键词匹配；未命中任何区间的标题延续上一个区间
- 子标题（H2–H4）仍在父级编号下逐级递增（如 `21.1`、`21.1.2`），H4 保持 `n、标题` 格式
- 可用 `subHeadings` 为个别子章节指定固定序号（支持嵌套）

#### 触发条件

页面属性（通常是 frontmatter）里的 `tags` 命中某条规则的 `tag` 时启用：

```yaml
---
tags: #你的规则标签
---
```

- 多个 tag 时按页面标签顺序匹配，**第一个命中的规则生效**
- 未命中任何规则的页面，仍走普通顺序编号
- 与标题编号一样，仅对文件型图谱生效

#### 规则文件

规则文件放在**插件安装目录**下（不是图谱目录，也不在仓库源码中），文件名即规则名：

```
{Logseq 插件目录}/left-sidebar-enhance/category-rules/{规则名}.json
```

最小格式示例（占位内容按需替换）：

```json
{
  "tag": "你的规则标签",
  "categories": [
    { "id": 1, "name": "前置区间", "positionBased": true },
    { "id": 2, "name": "区间二", "keywords": ["关键词A", "关键词B"] },
    {
      "id": 3,
      "name": "区间三",
      "keywords": ["关键词C"],
      "subHeadings": [
        { "number": 1, "keywords": ["子章节A"] }
      ]
    }
  ]
}
```

| 字段 | 说明 |
|---|---|
| `tag` | 与页面 `tags` 匹配的标签名（不带 `#`） |
| `categories[].id` | 区间 ID，决定十位数（`id: 2` → 编号从 20 起） |
| `categories[].positionBased` | 该区间使用位置法；通常为 `id: 1` |
| `categories[].keywords` | 关键词数组，标题包含任一即命中（忽略大小写与全/半角空格差异） |
| `categories[].subHeadings[].number` | 固定个位序号，可为 0（如 `30`） |
| `categories[].subHeadings[].keywords` | 子章节关键词；`subHeadings` 可继续嵌套 |

#### 启用与生效

在插件设置「启用的区间编号规则」中逐行填写规则名（即文件名去掉 `.json`）：

```
{规则名}
```

- 只有列出的规则会被加载；留空时只尝试加载 `人设标签`
- 规则文件缺失或 JSON 格式错误时，该规则会被跳过（控制台有 warning），页面回落到普通顺序编号
- 修改规则文件后需要重新加载插件（或改动一次插件设置）才会重新读取
- 规则文件必须真实存在，否则对应 tag 的页面不会启用预设规则编号

### 4. 自动调整标题等级（仅限文件型图谱）

根据块树的缩进深度自动规范 Markdown 标题等级，适用于 H1–H4 范围。

- **保留 H1** → 可选择将 H1 保留给页面标题
- **命令支持** → 通过命令面板（`Ctrl+Shift+P`）搜索「Normalize headings」即可规范化当前页面或选中区域的标题

### 5. 鼠标悬停唤出侧边栏

左侧边栏隐藏时，将鼠标移至左边缘即可临时唤出。

- **A 型** → 靠近左上角区域触发
- **B 型（推荐）** → 鼠标移到窗口最左列触发
- 通过左上角 `≡` 按钮或设置开关切换

### 6. 收藏夹和历史记录去重

启动时及每 10 分钟自动删除 Favorites 与 History 中的重复项。

## 安装

### 手动安装（推荐）

1. 从[发布页](https://github.com/Louis-15/logseq-plugin-left-sidebar-enhance/releases)下载最新的 `logseq-plugin-left-sidebar-enhance-*.zip`
2. 解压到 Logseq 插件目录下的 `left-sidebar-enhance` 文件夹（压缩包内文件直接放在该目录，不要多套一层）
3. 在 Logseq「设置 → 插件」中重新加载插件

> 本仓库是个人维护的版本，功能与上游 [YU000jp/logseq-plugin-left-sidebar-enhance](https://github.com/YU000jp/logseq-plugin-left-sidebar-enhance) 已有较大差异。Logseq 市场中的 `Left-Sidebar Enhance` 是上游版本，与本插件 id 相同（`left-sidebar-enhance`），请勿同时安装。

## 使用说明

- **页面大纲** — 打开任意页面，目录自动显示在左侧边栏
- **标题编号** — 点击页面工具栏的 `[1 2 3]` 图标重新编号；右键点击标题块圆点可设置跳过 / 跳过整棵子树 / 锁定 / 重复
- **预设规则编号** — 给页面加上规则对应的 tag（如 `tags: #你的规则标签`）即可启用；规则文件在插件目录 `category-rules/` 下
- **自动调整等级** — 通过命令面板（`Ctrl+Shift+P`）搜索「Normalize headings on current page」或「Normalize headings in selection」
- **鼠标悬停** — 点击左上角 `≡` 按钮在隐藏模式和悬停模式间切换

## 插件设置

| 设置项 | 说明 |
|--------|------|
| 隐藏收藏夹和历史记录中的重复项 | 启动时及每 10 分钟自动去重 |
| 鼠标悬停唤出侧边栏 | 启用/禁用，选择 A 型或 B 型 |
| 页面大纲（目录） | 启用/禁用，悬停高亮，日记日期列表 |
| 标题编号 | 按钮触发；通过块右键菜单配置 跳过 / 跳过整棵子树 / 锁定 / 重复上一个 |
| 启用的区间编号规则 | 每行一个规则名（文件名去掉 `.json`），对应插件目录下 `category-rules/{规则名}.json` |
| 自动调整标题等级 | 启用/禁用，保留 H1（标题范围固定 H1–H4） |

## 数据存储

标题状态（跳过 / 跳过整棵子树 / 锁定 / 重复）以 **Logseq 原生块属性** 的形式保存在块自身：

```
## 2.3 标题正文
numbering:: skip
```

- 属性键固定为 `numbering`，合法值为 `skip`、`skip-subtree`、`repeat`、`locked`
- 状态随块移动、复制、跨图谱同步，不再依赖 UUID 索引
- 插件会隐藏块属性面板中的该属性；如需**连编辑态也彻底隐藏**，请在 `config.edn` 中加入：

```clojure
:block-hidden-properties #{:numbering}
```

> 旧版本使用 `assets/storages/left-sidebar-enhance/` 下的 JSON 文件，现已不再读取，旧文件可以手动删除。**原 JSON 中的状态不会自动迁移**，升级后需要在块上重新标记。
